## Computational modeling theory
Have you picked up a scholarly book on culture and found yourself already cringing at the definition of "culture"?
"*A concept that encompasses the social behavior, institutions, and norms found in human societies, as well as the knowledge, beliefs, arts, laws, customs, capabilities, attitudes, and habits of the individuals in these groups.*" ([Wikipedia: Culture](https://en.wikipedia.org/wiki/Culture)). So basically everything, and therefore nothing in particular.  
I was on the lookout for a constructive definition of culture (i.e., one which is (theoretically) useful for constructing an instance of this definition). This all-encompassing "common definition" of culture is at best descriptive (and of questionable practical value). I found my way to a constructive definition of culture through Stephen Wolfram's computational (meta)modeling, which I shall describe in brief from my perspective here:  
Given a simple object and a simple set of rules, we can iteratively apply these rules to the object and its subsequent states. This process, where each step builds upon the previous one, can lead to surprisingly complex behavior, as exemplified by Stephen Wolfram's Rule 30 ([Wikipedia: Rule 30](https://en.wikipedia.org/wiki/Rule_30)). How complex? Possibly (hypothesizing) as complex as any natural phenomenon in the physical world. My computational approach to culture theory posits that we can model phenomena that are not easily understood or predicted through analytical or predictive methods (i.e., where the future state can be directly calculated from a past state via a known function) using this iterative, rule-based computation, i.e. with the assumption that the state at any future point can (only) be determined by computationally applying a set of rules to the current state and then repeating this process until the desired future point is reached. To use Stephen Wolfram terms, things that can be modelled through analytical or predictive methods are things with computational *reducibility* (whereas everything else has computational *irreducibility*).  
After studying the development of human cultures throughout history (to be summarized and discussed in a future chapter), it became clear that culture evolves in a step-wise manner, with each step building upon the last through the application of a set of underlying rules. This step-wise, rule-based development provides a constructive definition of culture, which is particularly useful when aiming to create new cultures. Therefore, studying Stephen Wolfram's computational framework can offer valuable insights into the process of culture creation. Unfortunately, in absolute terms, computational modeling theory is not nearly as useful than the theory of analytical or predictive methods, due to the fundamental complexity of the nature of things with computational irreducibility.
